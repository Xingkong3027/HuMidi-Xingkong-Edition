# HuMidi · Xingkong Edition

[English](README.md) · [下载](https://github.com/Xingkong3027/HuMidi-Xingkong-Edition/releases) · [更新记录](CHANGELOG.md)

当前版本：**2.1.2-xk.14**，基于 [HuMidi 2.1.2](https://github.com/smyGitt/HuMidi-Roblox-Piano-Autoplayer) 的 Rust / Tauri 2 / React 架构。星空版保留高级歌单、中文界面、每首歌曲独立设置、裁剪、模拟演奏策略、扩展快捷键与可选的密集 MIDI 性能优化。

这是非官方分支，由 Xingkong3027 维护；原项目作者为 smyGitt。

## 下载与启动

从本仓库 Releases 下载对应版本的 `HuMidi-Xingkong-Edition-<版本>-Windows-x64.exe`。Windows x64 单文件程序内嵌界面、图标和 PedalAI 模型，无需安装 Python、Node.js 或 Rust。运行电脑仍需 Microsoft Edge WebView2 Runtime。

本次交付目标为 Windows x64；尚未提供经过验证的 macOS / Linux 发行包。程序的数据目录为 `%USERPROFILE%/.humidi-xingkong-v2`。

## 基本使用

- 演奏：导入 MIDI，选择音轨，调整速度、移调、裁剪、踏板和模拟演奏，直接播放或加入歌单。
- 歌单：每首保留独立设置，支持批量修改、拖动排序、单曲、循环、顺序和随机播放。列表底部右侧的“全选”会选择整个歌库，包括搜索隐藏的歌曲；**Ctrl+A 可全选歌曲**，与按钮使用同一范围；在搜索框或其他编辑框内仍选择文字。Ctrl / Shift 可用于多选与连选。
- 转换：把 Virtual Piano 文本曲谱转换后播放或加入歌单。
- 设置：选择中文、英文或跟随系统，设置主题、窗口、全局演奏预设和双槽快捷键。默认 F6 播放/暂停、F7 停止；上一首、下一首需按需绑定。Ctrl+S 在程序窗口内保存当前曲目，Ctrl+K 切换紧凑模式。

只在歌曲自然结束时按歌单模式推进；手动停止、取消倒计时或更换来源会取消自动推进。

## 导入旧版歌单

选择 **歌单 → 导入歌单 → 选择新旧版歌单文件（推荐）**，直接打开 `.humidiplaylist`、`.json` 或 ZIP 完整包，无需解压，也无需选择文件夹。程序根据文件内容识别兼容格式。也可用这个入口选择旧歌库的 `index.json`。

“读取本地歌库文件夹”是另一种可选方式，适用于只有旧程序本机数据目录、没有导出文件的情况。详见[迁移指南](docs/MIGRATION.md)。

完整包携带 MIDI 原件、文本和缓存，适合备份或换电脑。普通包中的 MIDI 可能依赖原机文件路径；路径失效且没有可用缓存时，需要原件才能重新生成。原始文件和旧数据目录不会因导入被覆盖。

xk.11 修复了旧歌曲缺失踏板曲线时后台处理写入 `null`、随后无法播放的问题，也能兼容已经受影响的歌曲。后台处理提示保持固定占位，避免歌单列表反复上下跳动。

## 演奏与兼容性

设置 → 显示 → 窗口提供“播放时自动切换到 Roblox 窗口”和“本窗口获得焦点时暂停演奏”，均默认关闭，保留用户已保存的选择。两项同时开启时，倒计时后先确认 Roblox 获得焦点再检查暂停条件；演奏中主动切回本程序仍会暂停，手动继续可再次切到游戏。自动切换找不到游戏或被 Windows 拒绝时会暂停并提示。无论开关如何，本程序控件均不接收演奏按键。

密集 MIDI 性能优化默认关闭，并按歌曲保存；额外加速路径需要主动开启。关闭该选项不代表星空版所有导入规则、模拟演奏、缓存与停止处理都与上游逐字节相同。上游算法基准、测试范围和例外见[验证说明](docs/VALIDATION.md)。

相同原始 MIDI、选轨及有效演奏设置下，已验证旧完整包、新普通包、新完整包与直接导入 MIDI 的结果一致。只有旧缓存而没有原件时，程序恢复旧结果，不能保证它等同于新版重新解析 MIDI。开启“每次随机”的歌曲也不会保证每次生成完全一样。

MIDI 原件不改写。正常文件及完整音轨后的零填充不需要修复确认；检测到超出规范范围的通道数据字节时，先询问是否尝试兼容修复。此策略与上游宽容解析的处理方式存在差别。

已整合上游 2.1.2 的 PedalAI 权重、起音特征与自动峰值策略。旧歌曲的自定义曲线会保留；新模型仍可能改变相同曲线的踏板效果。Python 旧版与 Rust 版的随机算法也不保证逐音一致。
