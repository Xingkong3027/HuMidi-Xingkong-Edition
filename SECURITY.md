# Security Policy

## Supported versions

Security fixes are provided for the newest Xingkong Edition release. Preview
releases may contain incomplete features and should be tested before use.

## Reporting a vulnerability

Please open a private security advisory in the Xingkong Edition GitHub
repository when possible. Do not include Roblox credentials, session cookies,
private MIDI files, personal filesystem paths, or other secrets in a public
issue.

Repository:
<https://github.com/Xingkong3027/HuMidi-Xingkong-Edition/security/advisories>

## Update safety

The application checks only the Xingkong Edition GitHub Releases page. It does
not silently download or replace the running executable. Verify release asset
SHA-256 checksums before installing an update.

## Scope

HuMidi: Xingkong Edition generates keyboard input. Users are responsible for
following Roblox Terms, the rules of each Roblox experience, and applicable
local policies. The project must not be presented as an official Roblox or
official HuMidi product.
